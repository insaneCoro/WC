# WC26 League — GitHub Pages Wrapper

One file. Paste it on GitHub Pages and share the resulting URL instead of the script.google.com link.

## Deploy in 5 minutes

1. Go to **github.com** — sign in or create a free account
1. Click **+** (top right) → **New repository**
- Name: `wc26` (or anything)
- Set to **Public**
- Tick **Add a README file**
- Click **Create repository**
1. In the new repo, click **Add file → Upload files**
- Upload the `index.html` file from this folder
- Click **Commit changes**
1. Go to **Settings → Pages**
- Source: **Deploy from a branch**
- Branch: **main** / **(root)**
- Click **Save**
1. Wait ~60 seconds, refresh — GitHub shows your URL:
   `https://YOUR-USERNAME.github.io/wc26`

Share **that** URL. It works in Safari, Chrome, every browser.
